# Security policy

## Supported versions

Security fixes are provided for the latest major release.

## Reporting

Use GitHub’s private vulnerability reporting for `Ventairy/ship-my-flutter`. Include the affected version, impact, reproduction steps, and any suggested mitigation.

Do not include live App Store Connect keys, signing certificates, provisioning profiles, repository tokens, or credentials in the report. Revoke any credential that may have been exposed.

You should receive an initial acknowledgment within five business days. Please allow a reasonable remediation window before public disclosure.
